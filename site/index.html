The XCP-ng Developer's Handbook

Welcome to the home page of The XCP-ng Developer's Handbook.

This book is a comprehensive and progressive introduction to XCP-ng, an open-source virtualization platform. It is written for experienced software developers with no prior background in virtualization, infrastructure, or production environments, and guides the reader from the first principles of virtualization to the practical details of contributing to the project.

The sources of this book are a collection of Org-Mode files maintained in a public repository on GitHub.
